| --- | --- |

## Среда

Проверено с Python 3.12 и Django 5.2.18. Для хранения данных используется SQLite.
Методичка написана для Python 3.7 и Django 2.1; здесь используются совместимые
по назначению конструкции Django 5.2: path с int-конвертером, свойство
is_authenticated, __str__ и шаблонный тег static. Старые примеры с ошибками
не копируются буквально.

## Запуск

Открыть терминал в выбранной папке lab1–lab7 и выполнить:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py loaddata fixtures/demo.json
.\.venv\Scripts\python.exe manage.py changepassword mikhail
.\.venv\Scripts\python.exe manage.py runserver
```

Команда changepassword предлагает задать пароль для учебной учетной записи
mikhail. Файлы fixtures/demo.json содержат учебные записи, использованные
в работах: пользователей и, начиная с lab3, статьи. Готовых паролей и сессий
в них нет. В примерах выбраны шесть студентов из списка группы БСТ2353.
Для имен, приведенных в списке инициалами, сохранены инициалы.
Оценки учебные и не отражают фактическую успеваемость.
Повторная загрузка fixture восстанавливает исходные учебные записи.

Открыть http://127.0.0.1:8000/; в lab1 — http://127.0.0.1:8000/admin/.
В lab5 для создания статьи сначала войти в /admin/ под mikhail.
В lab6–lab7 можно зарегистрировать новую учетную запись через /register/
и войти через /login/. Для существующих учебных пользователей пароль
задается отдельно командой changepassword.

Для консольной части lab1:

```powershell
py helloworld.py
py mygroup.py
```

В mygroup.py вводится порог среднего балла. Результат содержит студентов
со средним баллом строго выше введенного значения.

В lab3 исходные три статьи созданы через административное приложение,
текст первой и заголовок второй изменены SQL-командами, две записи
добавлены напрямую в SQLite. Fixture сохраняет итоговое состояние.

## Публикация репозитория

Выполнить из корня этого каталога:

```text
git init -b main
git add .
git commit -m "Лабораторные работы по ПИС"
git remote add origin <URL вашего пустого репозитория>
git push -u origin main
```

Имя репозитория выбирается самостоятельно. При первом коммите Git может
попросить настроить user.name и user.email для своего аккаунта.
